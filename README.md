# 🎸 Tab Maker (기타 타브 메이커)

음악 지식이 없어도 인터넷·유튜브의 기타 타브 악보를 보고 그대로 옮겨 적을 수 있게 만든 기타 전용 악보 프로그램.

- **바로 쓰기:** https://humph92y.github.io/tab_maker/ (아이패드 Safari → 공유 → 홈 화면에 추가)
- 클릭 + 숫자 + Enter 로 프렛 입력, M 마디, B 벤딩, S 슬라이드, H 해머/풀
- 리듬 자동 추천, 피킹(⊓/V) 추천, 손가락(운지) 색 추천
- 연속 재생(클린/디스토션), 메트로놈, 구간 반복
- PDF 저장, Guitar Pro/MuseScore PDF 악보 자동 인식
- 설치 없음: `index.html` 하나로 동작 (인터넷 연결 불필요)

자세한 사용법은 `사용법.txt` 또는 프로그램의 **도움말** 탭(F1)을 보세요.

### 사용한 오픈소스
- [pdf.js](https://github.com/mozilla/pdf.js) (Apache-2.0) — `lib/` 폴더, PDF 읽기
