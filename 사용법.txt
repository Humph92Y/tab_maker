🎸 기타 타브 메이커 - 사용법 (1단계 테스트 버전)

[실행 방법]
1. 이 폴더에서 index.html 파일을 더블클릭하세요.
   (크롬 또는 엣지 브라우저로 열립니다. 인터넷 연결이 없어도 됩니다.)
2. 처음 열면 예제 악보가 나와요. 왼쪽 위 [▶ 재생]을 눌러 들어보세요.
3. 새로 쓰려면 [📄 새 악보]를 누르세요.

[화면 구성]
- 위쪽 메뉴는 워드처럼 탭으로 나뉘어 있어요: 파일 / 입력 / 주법 / 곡 설정 / 재생 / 도우미 / 도움말
- F1 키 또는 [도움말] 탭 → 단축키 전체 보기
- 새 악보는 빈 마디 8개(한 줄에 4마디)로 시작해요. 곡 설정 탭에서 한 줄 마디 수를 바꿀 수 있어요.

[악보 쓰기]
- 줄 위를 클릭 → 숫자(프렛) 입력 → Enter : 그 줄, 그 위치에 저장되고 다음 칸으로 이동
- 숫자 사이에 마우스를 올리면 초록 선 → 클릭하면 그 자리에 새 칸이 끼워져요
- 쉼표 : 입력 탭의 쉼표 버튼(온/2분/4분/8분/16분) 또는 R 키
- 숫자를 한 번 클릭 : 수정 / 삭제 / 손가락 색 / 주법 메뉴
- M : 마디 나누기 (마디 끝에서 누르면 새 마디)
- B : 벤딩 (누를 때마다 full → ½ → 1½ → 벤딩&릴리즈 → 없음)
- S : 슬라이드 (숫자 선택 → S → 이어질 다음 숫자 클릭)
- H : 해머온/풀오프 (S와 같은 방법)
- V 비브라토, P 팜뮤트, X 데드노트, G 고스트, L 렛링, A 악센트
- Q : 꾸밈음 (작은 숫자, 박자를 차지하지 않음. 예: 작은 9 → H → 11)
- + / - : 음표 길이 길게/짧게,  . 점음표,  T 셋잇단,  R 쉼표
- 줄 아래 리듬 표시를 클릭 : 음표 길이 선택 + [이 마디 리듬 자동 추천]
- 줄 위 피킹 칸 클릭 (또는 D / U 키) : ⊓ 다운 / V 업 직접 입력
- Ctrl+Z 되돌리기, Ctrl+Y 다시 실행, Space 재생/정지

[도우미]
- 🖐 운지 추천 : 앞뒤 음을 모두 보고 손가락을 색으로 표시 (검지 파랑, 중지 초록, 약지 주황, 새끼 보라)
  숫자를 클릭해서 손가락 색을 직접 바꾸면 그게 우선이고, 추천도 그에 맞춰 다시 계산돼요.
- ⊓V 피킹 추천 : 파란색 = 추천, 검정 = 직접 입력
- ✨ 리듬 자동 맞춤 : 박자가 안 맞는 마디(마디 번호에 ⚠ 표시)의 음표 길이를 자동으로 맞춤

[PDF 악보 자동 인식]
- 파일 탭 → 📥 PDF 악보 불러오기 → PDF 선택
- Guitar Pro, MuseScore 등 프로그램에서 내보낸 PDF를 인식해요 (스캔/사진 PDF는 아직 안 돼요)
- 숫자·줄·마디는 정확하고, 리듬은 오선보 기호 + 박자 합 규칙으로 맞춰요
- 마디 번호가 주황색(⚠)인 곳은 추측해서 맞춘 곳이니 원본과 비교해 주세요 (마디 번호 클릭 → ✓ 확인 완료)

[저장]
- 💾 저장 : 악보 파일(.gtab.json)이 다운로드 폴더에 저장돼요. 📂 열기로 다시 불러와요.
- 🖨 PDF 저장 : 인쇄 창이 뜨면 "대상"을 "PDF로 저장"으로 고르고 저장을 누르세요.
- 작업 중인 악보는 브라우저에 자동 저장돼요. 그래도 중요한 악보는 💾 저장을 꼭 눌러주세요.
