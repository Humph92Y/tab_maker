🎸 기타 타브 메이커 - 사용법 (1단계 테스트 버전)

[실행 방법]
1. 이 폴더에서 index.html 파일을 더블클릭하세요.
   (크롬 또는 엣지 브라우저로 열립니다. 인터넷 연결이 없어도 됩니다.)
2. 처음 열면 예제 악보가 나와요. 왼쪽 위 [▶ 재생]을 눌러 들어보세요.
3. 새로 쓰려면 [📄 새 악보]를 누르세요.

[화면 구성]
- 위쪽 메뉴는 워드처럼 탭으로 나뉘어 있어요: 파일 / 입력 / 주법 / 곡 설정 / 재생 / 도우미 / 도움말
- F1 키 또는 [도움말] 탭 → 단축키 전체 보기
- 새 악보는 빈 마디 8개(한 줄에 4마디)로 시작해요. 곡 설정 탭에서 한 줄 마디 수를 바꿀 수 있어요.

[악보 쓰기]
- 줄 위를 클릭 → 숫자(프렛) 입력 → Enter : 그 줄, 그 위치에 저장되고 다음 칸으로 이동
- 숫자 사이에 마우스를 올리면 초록 선 → 클릭하면 그 자리에 새 칸이 끼워져요
- 쉼표 : 입력 탭의 쉼표 버튼(온/2분/4분/8분/16분) 또는 R 키
- 숫자를 한 번 클릭 : 수정 / 삭제 / 손가락 색 / 주법 메뉴
- M : 마디 나누기 (마디 끝에서 누르면 새 마디)
- B : 벤딩 (누를 때마다 full → ½ → 1½ → 벤딩&릴리즈 → 없음)
- S : 슬라이드 (숫자 선택 → S → 이어질 다음 숫자 클릭)
- H : 해머온/풀오프 (S와 같은 방법)
- V 비브라토, P 팜뮤트, X 데드노트, G 고스트, L 렛링, A 악센트
- Q : 꾸밈음 (작은 숫자, 박자를 차지하지 않음. 예: 작은 9 → H → 11)
- + / - : 음표 길이 길게/짧게,  . 점음표,  T 셋잇단,  R 쉼표
- 줄 아래 리듬 표시를 클릭 : 음표 길이 선택 + [이 마디 리듬 자동 추천]
- 줄 위 피킹 칸 클릭 (또는 D / U 키) : ⊓ 다운 / V 업 직접 입력
- Ctrl+Z 되돌리기, Ctrl+Y 다시 실행, Space 재생/정지

[도우미]
- 🖐 운지 추천 : 앞뒤 음을 모두 보고 손가락을 색으로 표시 (검지 파랑, 중지 초록, 약지 주황, 새끼 보라)
  숫자를 클릭해서 손가락 색을 직접 바꾸면 그게 우선이고, 추천도 그에 맞춰 다시 계산돼요.
- ⊓V 피킹 추천 : 파란색 = 추천, 검정 = 직접 입력
  · 실제로 치는 음에만 붙여요. 쉼표, 붙임줄로 이어지는 음, 해머/풀·슬라이드로 이어지는 음은 치지 않아서 기호가 없어요
  · 화음은 한 번 치는 것이라 기호 1개
  · 방식 '박자 맞춤'(기본): 손목을 박자에 맞춰 계속 위아래로. 박의 앞은 ⊓, 뒤는 V (쉼표 자리도 손은 움직여요)
  · 방식 '무조건 번갈아': 치는 음마다 ⊓ V ⊓ V (직접 입력한 피킹 다음부터 반대로 이어가요)
  · 직접 입력한 피킹(검정)은 추천이 바꾸지 않아요
- ✨ 리듬 자동 맞춤 : 박자가 안 맞는 마디(마디 번호에 ⚠ 표시)의 음표 길이를 자동으로 맞춤

[PDF 악보 자동 인식]
- 파일 탭 → 📥 PDF 악보 불러오기 → PDF 선택
- Guitar Pro, MuseScore 등 프로그램에서 내보낸 PDF를 인식해요 (스캔/사진 PDF는 아직 안 돼요)
- 리듬은 오선보 기호(기둥·빔·꼬리·점·겹점·쉼표·스타카토·붙임줄)를 읽어서 그대로 옮겨요
- 원본에서 읽은 길이는 박자 합이 안 맞아도 몰래 바꾸지 않아요. 대신 그 마디를 주황색(⚠)으로 표시하고 이유를 적어 둬요
- 마디 번호 클릭 → "📄 PDF에서 읽을 때" 줄에 이유가 나와요. 원본과 비교한 뒤 🔧 해결 버튼이나 ✓ 확인 완료를 누르세요
- 오선보 없이 타브만 있는 악보는 숫자 간격으로 길이를 추측해요 (추측한 마디도 ⚠ 표시)

[저장]
- 💾 저장 : 악보 파일(.gtab.json)이 다운로드 폴더에 저장돼요. 📂 열기로 다시 불러와요.
- 🖨 PDF 저장 : 인쇄 창이 뜨면 "대상"을 "PDF로 저장"으로 고르고 저장을 누르세요.
- 작업 중인 악보는 브라우저에 자동 저장돼요. 그래도 중요한 악보는 💾 저장을 꼭 눌러주세요.

==============================
새 기능 (쉽게 만들기)
==============================
1) 음표 길이 자동 맞춤
   - 숫자만 차례로 넣고 M(마디)을 누르면, 그 마디의 음표 길이를 자동으로 맞춰줘요.
   - 다른 마디로 이동해도 자동으로 맞춰요. (입력 탭 → "리듬 자동 맞춤"으로 켜고 끔)
   - 숫자 아래(리듬)를 누르면 "리듬 후보"가 나와요. ▶로 들어보고 마음에 들면 [적용].
   - 직접 고른 길이는 자동 맞춤이 바꾸지 않아요.

2) ⚠ 오류 해결
   - 마디 번호 옆 ⚠ 또는 맨 아래 상태줄의 "몇 박 채움"을 누르면
     왜 틀렸는지 설명과 [🔧 해결] 버튼이 나와요. 누르면 자동으로 고쳐져요.

3) 선생님 설명
   - 마디를 클릭하면 그 줄 아래에 "이렇게 쳐 보세요" 설명이 나와요.
     박자 세는 법, 줄·프렛·손가락·피킹, 주법 설명, 손 위치와 연습 팁.
   - 🔁 버튼으로 그 마디만 70% 속도로 반복 연습할 수 있어요.
   - 끄고 켜기: 도우미 탭 → "선생님 설명"

4) 음악 기초
   - 도움말 탭 → 🎵 음악 기초 : 타브 읽는 법, 음표/쉼표 길이, 점음표, 셋잇단,
     붙임줄, 박자표, 피킹 기호, 주법 기호, 손가락 번호를 정리해 뒀어요.

5) PDF 인식 보정
   - 원본에서 읽은 음표 길이는 그대로 두고, 박자 합이 안 맞는 마디는 ⚠ 로 표시만 해요.
   - 주황색 ⚠ 마디는 박자가 안 맞거나 추측한 곳이에요. 눌러서 ▶ 들어보고 [✓ 확인 완료] 또는 리듬 후보를 고르세요.

==============================
휴대폰 · 아이패드에서 쓰기
==============================
- PC, 아이패드, 휴대폰 모두 같은 주소에서 화면 크기에 맞춰 자동으로 바뀌어요.
  https://humph92y.github.io/tab_maker/
- 앱처럼 쓰기: Safari에서 열고 공유 버튼(□↑) → "홈 화면에 추가".
  홈 화면 아이콘으로 열면 주소창 없이 앱처럼 꽉 찬 화면으로 열려요.
- 숫자 입력:
  · 화면 아래 숫자 패드(0~24)를 누르면 바로 들어가고 다음 칸으로 넘어가요.
  · 패드의 "⌨ 자판"을 누르면 아이폰/아이패드 숫자 자판으로 입력해요.
    3~9는 누르자마자, 12처럼 1·2로 시작하는 두 자리는 이어서 누르면 돼요.
  · 패드를 숨겼을 때 오른쪽 아래 🔢 버튼으로 다시 열 수 있어요.

==============================
악보 파일 저장 · 다른 기기로 옮기기
==============================
- 💾 저장 = 공통 악보 파일(.musicxml)로 저장해요.
  Guitar Pro, MuseScore, TuxGuitar 등 다른 악보 프로그램에서도 열려요.
- 🗂 백업 저장 = 이 프로그램 전용 파일(.gtab.json).
- 📂 열기 = .musicxml / .xml / .mxl / .gtab.json 을 모두 열 수 있어요.
  (PDF는 "PDF 악보 불러오기"로 따로 열어요)

아이패드 → PC로 옮기는 방법
1) 아이패드에서 💾 저장 → "파일" 앱 → "다운로드" 폴더에 .musicxml 파일이 생겨요.
   (또는 📤 보내기 → AirDrop, 카카오톡, 메일, "파일에 저장" 중 고르기)
2) "파일" 앱에서 그 파일을 길게 눌러 → 복사 → USB 메모리(파일 앱 왼쪽 목록에 보여요)에 붙여넣기.
3) PC에 USB를 꽂고, 타브 메이커에서 📂 열기 → USB의 .musicxml 파일 선택.

==============================
톤 · 효과 · 메뉴 숨기기
==============================
- 재생 탭 → 톤: 클린 / 크런치 / 오버드라이브 / 디스토션 / 어쿠스틱(통기타). 고르면 짧게 들려줘요.
- 효과(선택): 리버브(공간감), 딜레이(메아리). 체크로 켜고 끄고, 막대로 양을 조절해요.
  딜레이 간격(8분 / 점8분 / 4분)은 곡 빠르기에 자동으로 맞춰져요. 재생 중에도 바로 바뀌어요.
- 위 메뉴 숨기기: 왼쪽 위 ▴ 버튼 → 메뉴가 숨고 악보가 넓어져요. "☰ 메뉴"를 누르면 다시 나와요.

==============================
한 박 리듬 (가장 쉬운 리듬 입력)
==============================
- 악보에서 가로 막대(빔)로 묶인 덩어리 하나 = 보통 1박이에요.
- 그 덩어리의 첫 숫자(또는 쉼표 칸)를 누르면 창 맨 위에 "🥁 한 박 리듬" 모양들이 나와요.
  악보와 같은 모양을 누르면 그 칸부터 숫자 개수만큼 한 번에 길이가 맞춰지고, 다음 박으로 넘어가요.
  예) 𝄾♬ = 8분쉼표 + 16분 + 16분,  ♪♬ = 8분 + 16분 + 16분
- 쉼표가 있는 모양인데 쉼표 칸이 없으면 자동으로 쉼표 칸을 끼워 넣어요.

슬라이드 / 해머 연결
- 숫자를 누르면 "같은 줄: 앞 ○ · 지금 · 다음 ○"이 보여요. 슬라이드는 항상 같은 줄의 바로 앞/다음 숫자와 이어져요.
- [← 앞에서 슬라이드] 또는 [슬라이드 → 다음] 버튼을 누르면 바로 연결돼요. (S/H 키도 바로 다음 숫자와 연결)
